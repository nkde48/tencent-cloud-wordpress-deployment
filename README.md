## 腾讯云宝塔搭建网站要买什么配置？

2核2G 是实际起点，1核1G 不建议。宝塔面板 11.0 在 1核1G 环境下面板本身占 200MB 左右内存，但 LNMP 里的 MySQL 和 PHP 还要占内存，WordPress 再跑起来，1G 内存很容易在装数据库或上传图片时卡住。

带宽和流量按站点类型选：

- 个人博客、作品集：2核2G/3M，200G 月流量，日均几百访问问题不大
- 企业官网、产品展示：2核2G/4M 或 2核4G/6M，图片多就往上加
- 要跑商城、论坛、多站点：4核8G/5M 起步

硬盘方面，40G SSD 装一个 WordPress 加插件、主题、图片够用；如果打算长期存大量素材，70G 或 180G 更省心。

## 腾讯云宝塔搭建网站的完整流程

一共七步：买服务器、重置密码登录、开放防火墙端口、装宝塔面板、装 LNMP 环境、部署 WordPress、解析域名并上 HTTPS。买带宝塔镜像的服务器可以跳过第四步。

### 第一步：买服务器，镜像有两条路

在腾讯云轻量应用服务器购买页选「基于操作系统镜像」，系统推荐 Ubuntu 24.04 LTS；也可以直接在应用镜像里选宝塔面板，开机后宝塔已经装好，省去手动安装这一步。

地域选离自己近的节点。国内节点访问快，但域名需要备案；香港节点免备案，买完当天就能开始搭建，适合不想等备案的用户。

配置按前面的建议选，买完等 1 到 3 分钟实例初始化完成。

### 第二步：重置密码并登录

进入轻量应用服务器控制台，点「重置密码」，选在线重置，输入新密码。Ubuntu 系统的默认登录用户名是 `ubuntu`，不是 root。

登录方式有两种：直接在腾讯云控制台点「登录」，或者用 Xshell、终端等工具连公网 IP。用 Xshell 的话，新建会话填服务器公网 IP，协议选 SSH，再输入用户名和刚重置的密码。

### 第三步：开放防火墙端口

在轻量应用服务器控制台的「防火墙」里添加规则，至少放行这几个端口：

- 22：SSH 远程连接
- 80：HTTP 网站访问
- 443：HTTPS 网站访问
- 8888 或宝塔实际使用的面板端口：宝塔管理后台

授权对象选 `0.0.0.0/0`，新手先这样设置，后面再收紧。这一步没做，后面宝塔地址一定打不开。

### 第四步：安装宝塔面板

用 Ubuntu 系统的话，SSH 登录后执行：

bash
wget -O install_panel.sh https://download.bt.cn/install/install_panel.sh && sudo bash install_panel.sh ed8484bec


系统会问是否确认安装，输入 `y` 回车。整个过程几分钟，完成后终端会显示面板地址、用户名和密码，务必保存下来。

装完再用 `bt` 命令可以改面板端口、改密码、重启面板。输入 `bt` 回车就能看到菜单。

如果你买的是宝塔应用镜像，这一步跳过，登录信息在实例详情里。

👉 直接选带宝塔面板镜像的服务器，开机就能用

### 第五步：安装 LNMP 环境

登录宝塔面板后，第一次进入会推荐安装 LNMP。也可以在「软件商店」里手动选 Nginx、MySQL、PHP 安装。PHP 建议 7.4 以上，WordPress 新版对 PHP 版本有要求，版本太低会在安装时被拦下来。

编译安装通常要半小时到 1 小时，取决于服务器性能。这期间不用守着，装完面板会有提示。

### 第六步：部署 WordPress

宝塔提供两种部署方式，选一种就行。

**一键部署**：软件商店 → 一键部署 → 找到 WordPress → 点部署。如果提示「缺少被支持的 PHP 版本」，先回软件商店装 PHP；提示安装数据库就点立即安装；提示装 Nginx 也一样。环境补齐后重新点部署，填上域名，宝塔会自动建站、建数据库。部署完成后把页面上的数据库名、用户名、密码复制下来。

**手动上传**：在 WordPress 中文官网下载安装包，解压后把里面的文件重新压成 zip（服务器不支持 rar 解压），上传到 `/www/wwwroot/你的域名` 目录，解压并删除压缩包。然后浏览器访问域名，会跳转到 WordPress 安装页。

两种方式最后都要填数据库信息：数据库名、用户名、密码填宝塔里创建的那组，数据库主机填 `localhost`，表前缀保留默认的 `wp_` 即可。提交后设置站点标题、管理员账号、密码和邮箱，安装完成。

### 第七步：域名解析和 HTTPS

在域名管理后台添加两条 A 记录：主机记录 `@` 指向服务器公网 IP，主机记录 `www` 也指向同一个 IP。等待几分钟到几小时生效，可以用 `ping 你的域名` 检查是否已经指向正确 IP。

解析生效后，在宝塔的网站设置里找到 SSL，选 Let's Encrypt 免费证书申请，一键部署，再打开「强制 HTTPS」。这样浏览器地址栏会显示锁标，也不会因为 HTTP 被标记为不安全。

## 新手最容易卡住的 5 个地方

按出现频率排，依次是端口、系统版本、PHP、内存和备案。下面逐条说清楚。

**端口没放行。** 宝塔装好了，浏览器打开面板地址一直转圈，九成是防火墙没开端口。腾讯云轻量服务器的防火墙在控制台单独管理，和宝塔里的防火墙是两回事，两边都要放行。

**还在用 CentOS 7。** CentOS 7 已经在 2024 年 6 月 30 日停止维护，不再提供安全更新。网上很多老教程还在教 CentOS 7 装宝塔，照着做后面会遇到软件源失效的问题。新买服务器选 Ubuntu 24.04 或 Rocky Linux 9，宝塔 11.0 对这两个系统都有适配。

**PHP 没装就点一键部署。** 宝塔的一键部署不会自动帮你补齐所有依赖，缺 PHP 会直接报错。正确顺序是先装 PHP、MySQL、Nginx，再部署 WordPress。

**1核1G 硬跑 WordPress。** 面板能装，环境也能装，但 MySQL 启动后内存就所剩不多，上传图片或装插件时容易 502。2核2G 是更稳妥的起点。

**域名没备案。** 国内节点必须备案，通常要花几周时间；香港节点免备案，买完就能用。如果网站只是自己看或给海外用户看，香港节点省事很多。

## 宝塔装好之后，安全上至少做三件事

第一件，改面板端口。默认的 8888 很容易被扫描，在面板设置里改成 8888 到 65535 之间一个不常见的数字。改完记得回腾讯云控制台防火墙放行新端口，否则会直接登不上面板。

第二件，开 BasicAuth 认证。在设置 → 安全设置里打开，访问面板前要多输一次账号密码，能挡掉大部分自动化扫描。

第三件，设自动备份。在「计划任务」里添加任务，选择备份数据库或备份网站文件，频率设成每天或每周，备份文件可以存本地，也可以传到远程云存储。网站数据丢了再想起来备份就晚了。

不是。Ubuntu 24.04、Rocky Linux 9 都可以，关键是别用已经停止维护的 CentOS 7。

不需要。国内节点需要备案，香港节点免备案，买完即可搭建。

**WordPress 安装时数据库信息填什么？**
